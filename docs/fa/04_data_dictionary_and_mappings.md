# ۰۴ - فرهنگ داده و نگاشت‌ها

همه‌ی قانون‌هایی که فایل‌های Excel خام را به یک دیتاست استاندارد تبدیل می‌کنند. نگاشت‌ها در [`src/cleaner.py`](../../src/cleaner.py) هستند و این صفحه همه را یک‌جا فهرست می‌کند. (در نسخه‌ی عملیاتی باید به پیکربندی / داده‌ی مرجع منتقل شوند؛ [`03_production_improvements.md`](03_production_improvements.md) را ببینید.)

## ۱. ستون‌های استاندارد داده‌ی هزینه‌ی پاک‌سازی‌شده

| ستون | معنی |
|---|---|
| `company` | شرکتی که هزینه به آن تعلق دارد (`ALL` برای هزینه‌ی مشترک) |
| `cost_title` | هزینه برای چه چیزی است |
| `amount` | مبلغ به ریال |
| `period` | ماه، همیشه به شکل `YYYY/MM` (شمسی)، مثلاً `1405/03` |
| `allocation_type` | `Direct` یا `Shared_Headcount` |
| `description`، `reference` | متن آزاد و کد پیگیری یا مرکز هزینه (نگه داشته می‌شوند، در محاسبه استفاده نمی‌شوند) |

داده‌ی تعداد نفرات سه ستون دارد: `company`، `headcount` و `period`.

## ۲. نام ستون‌هایی که نگاشت می‌شوند

| ستون استاندارد | نام‌های موجود در فایل‌ها |
|---|---|
| `company` | `نام شرکت`، `شرکت`، `Company`، `Company Name` |
| `amount` | `مبلغ`، `مبلغ (ریال)`، `Amount (Rial)` |
| `cost_title` | `شرح خدمت`، `نوع خدمت`، `عنوان هزینه`، `Cost Title` |
| `description` | `شرح`، `توضیحات` |
| `period` | `ماه`، `دوره`، `Period`، `Month` |
| `allocation_type` | `روش تخصیص`، `نحوه تخصیص`، `مبنای تسهیم`، `Allocation Basis` |
| `reference` | `Reference`، `کد پیگیری`، `مرکز هزینه` |
| `headcount` | `تعداد نفرات`، `Headcount` |

ستون‌هایی که حذف می‌شوند چون فقط ردیف‌ها را شماره می‌زنند یا وضعیت دارند: `ردیف`، `شماره`، `وضعیت`.

## ۳. نام شرکت‌ها

| نام استاندارد | املاهای نگاشت‌شده به آن |
|---|---|
| `Alpha company` | `Alpha`، `آلفا`، `شرکت آلفا`، `Alpha Co` |
| `Beta company` | `بتا`، `شرکت بتا`، `Beta Co` |
| `Gamma company` | `Gamma Co`، `گاما`، `شرکت گاما` |
| `Delta company` | `دلتا`، `شرکت دلتا`، `Delta Co` |
| `Epsilon company` | `Epsilon`، `اپسیلون`، `شرکت اپسیلون` |
| `Omega company` | `شرکت امگا` (در فهرست نفرات نیست، پس سهم هزینه‌ی مشترک ندارد) |
| `ALL` | `همه`، `همه شرکت‌ها` |

## ۴. نوع تخصیص

| مقدار استاندارد | مقدارهای نگاشت‌شده به آن |
|---|---|
| `Direct` | `مستقیم`، `Direct` |
| `Shared_Headcount` | `مشترک`، `Headcount`، `تعداد نفرات`، `مساوی`، `Equal` |

`مساوی` / `Equal` (تقسیم مساوی) فعلاً مثل تقسیم بر اساس نفرات گرفته می‌شود؛ تصمیم‌های باز را ببینید.

## ۶. قانون‌های مقدار

| وضعیت | قانون |
|---|---|
| دوره به شکل `1405-03` | به `1405/03` تبدیل می‌شود |
| عدد خالی (مبلغ یا تعداد نفرات) | صفر، همراه با هشدار |
| مبلغ منفی | صفر، همراه با هشداری که رکورد را نشان می‌دهد |
| ردیفی که با ردیف دیگر یکسان است (بعد از حذف ستون‌های شماره‌ی ردیف) | یک بار نگه داشته می‌شود، همراه با هشدار |
| ردیفی که دوره‌اش با بقیه‌ی فایل فرق دارد | نگه داشته می‌شود، همراه با هشداری که ردیف را نشان می‌دهد |
| هزینه‌ی مستقیم | برای همان شرکت می‌ماند |
| هزینه‌ی مشترک | `هزینه ÷ مجموع نفرات ماه × نفرات شرکت` |
